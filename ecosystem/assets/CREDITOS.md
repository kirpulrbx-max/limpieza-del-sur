# Créditos de recursos externos

Todos los recursos de esta carpeta tienen licencia **CC0 (dominio público)**: se pueden
usar, modificar y distribuir, también comercialmente, sin atribución obligatoria.

## Modelos 3D — Poly Haven (https://polyhaven.com)

Formato glTF, texturas 1K (recomprimidas a JPG para reducir tamaño).

| Modelo | Uso en el juego |
|---|---|
| fern_02 | Helecho Burbuja |
| anthurium_botany_01 | Lirio Prisma |
| pachira_aquatica_01 | Árbol Aurora |
| shrub_03, shrub_sorrel_01, calathea_orbifolia_01, flower_empodium | Vegetación decorativa que brota con la vitalidad |
| moon_rock_02, moon_rock_03, moon_rock_06, rock_09 | Rocas decorativas |

## Texturas — ambientCG (https://ambientcg.com)

| Textura | Uso |
|---|---|
| Grass004 (color + normal, 1K) | Detalle de la superficie de las islas |
| Rock035 (color + normal, 1K) | Detalle de la base rocosa de las islas |

Si falta algún archivo, el juego recurre automáticamente a los modelos procedurales.
